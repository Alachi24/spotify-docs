# Overview

Welcome to the Spotify Web API documentation! This is your starting point for building amazing music applications.

### Getting Started

1. **Log In to the Dashboard**  
   Access the [Spotify Developer Dashboard](https://developer.spotify.com/dashboard/) with your Spotify account.

2. **Create an App**  
   Create a new app for the Web API, and get your **Client ID and Client Secret** for authorization.

3. **Use the Access Token**  
   Include the access token in API requests to authenticate.

4. **Follow the Tutorial**  
   Check out the [Getting Started Tutorial](/docs/Documentation/Getting_Started) for your first API call.

### Documentation Structure

- **Concepts**: Key topic explanations.
- **Tutorials**: Beginner guides.
- **How-Tos**: Practical step-by-step instructions.
- **Reference**: Full API specs and endpoint details, accessible via the sidebar.

### API Capabilities

- Retrieve data on artists, albums, and shows.
- Search Spotify content.
- Control playback and manage your library.
- Explore more in the [API Reference](/docs/spotify/albums)
